## 📋 Características

- **Design Minimalista**: Interface limpa e elegante com estética preto e branco
- **CRUD Completo**: Criar, visualizar, editar e excluir tarefas
- **Filtros Dinâmicos**: Filtragem por status, prioridade e categorias
- **Pesquisa Instantânea**: Busca em tempo real com feedback imediato
- **Persistência Local**: Armazenamento persistente via LocalStorage
- **Seletor de Data**: Integração com FlatPickr para datas e prazos
- **Notificações Elegantes**: Sistema de notificações com Toastr
- **Responsividade Total**: Adaptação perfeita para qualquer dispositivo
- **Drag & Drop**: Reorganização intuitiva das tarefas por prioridade
- **Modo Escuro/Claro**: Alternância entre temas com transições suaves

## 🔧 Tecnologias Utilizadas

- JavaScript moderno para lógica da aplicação
- jQuery 3 para manipulação do DOM e AJAX
- HTML5 semântico para estrutura
- CSS3 com variáveis para temas e animações
- FlatPickr para seleção elegante de datas
- Toastr para sistema de notificações
- LocalStorage para persistência de dados
- CSS Grid e Flexbox para layout responsivo
- Animações CSS para transições suaves

## 🚀 Como Usar

1. Acesse o [gerenciador online](https://gerenciador-de-tarefas-marcelo.netlify.app/)
2. Funcionalidades principais:
   - Clique em "Nova Tarefa" para adicionar
   - Clique nas tarefas para expandir detalhes
   - Use os ícones para editar, completar ou excluir
   - Utilize os filtros no topo para organizar a visualização
   - Use a barra de pesquisa para encontrar tarefas específicas
   - Arraste e solte para reorganizar prioridades
